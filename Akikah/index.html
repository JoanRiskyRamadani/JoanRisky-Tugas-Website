Doa Aqiqah

اَللّٰهُمَّ هٰذِهِ عَقِيْقَةٌ عَنْ (اسم الطفل) لَحْمُهَا بِلَحْمِهِ وَدَمُهَا بِدَمِهِ وَعَظْمُهَا بِعَظْمِهِ وَشَعْرُهَا بِشَعْرِهِ وَجِلْدُهَا بِجِلْدِهِ. اَللّٰهُمَّ اجْعَلْهَا فِدَاءً لَهُ مِنَ النَّارِ

"Ya Allah, ini adalah aqiqah untuk Muhammad Fatih, dagingnya untuk dagingnya, darahnya untuk darahnya, tulangnya untuk tulangnya, rambutnya untuk rambutnya, dan kulitnya untuk kulitnya. Ya Allah, jadikanlah aqiqah ini sebagai penebus baginya dari api neraka"
